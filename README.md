# 💧 Water Potability Prediction System

🚀 An **interactive Machine Learning application** built using **Streamlit** to predict whether water is **safe for consumption** based on chemical properties.

---

## 🌟 Key Features

* 🤖 **ML-Based Prediction** using **Ensemble Models** (LightGBM, CatBoost, Extra Trees, Neural Network)
* 📊 **Interactive Dashboard** with **EDA visualizations**
* ⚖️ **Class Imbalance Handling** using **SMOTEENN**
* 🧠 **Advanced Feature Engineering** for improved accuracy
* 🔍 **Real-Time Predictions** with confidence score
* 📈 **Model Performance Metrics** (Accuracy, ROC-AUC, F1-score)

---

## 🛠️ Tech Stack

* **Python**
